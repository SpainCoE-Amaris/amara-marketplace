# Amara Marketplace

Amara Marketplace is a collection of AI development plugins focused on practical engineering workflows, reusable skills, and specialized agents.

This repository currently includes plugin packs for .NET and Vue-oriented development scenarios and is designed to grow with more agents and skills over time.

## How To Use

1. Open VS Code.
2. In your session settings, configure marketplace sources by adding this entry:

```json
"chat.plugins.marketplaces": [
	"https://github.com/SpainCoE-Amaris/amara-marketplace.git"
]
```

3. Reload the VS Code window if required.
4. Browse and use the plugins from this marketplace.
5. Review each plugin README and skill definitions before integrating them into your workflow.
